# Práctica de GitHub

## Descripción

Esta es una práctica para aprender a utilizar GitHub.

## Objetivo

Aprender a crear un repositorio, agregar archivos y realizar cambios mediante commits.

## ¿Qué es GitHub?

GitHub es una plataforma que permite guardar, compartir y administrar proyectos y código.
