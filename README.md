# 🎵 MusicWave

## 📌 Descripción

MusicWave es una página web de música creada como proyecto educativo utilizando HTML, CSS y JavaScript.

La página permite explorar diferentes géneros musicales, buscar canciones y reproducir pistas de demostración mediante un reproductor integrado.

## 🎧 Características

- Explorar diferentes géneros musicales.
- Buscar canciones por nombre, artista o género.
- Mostrar canciones mediante tarjetas.
- Reproducir canciones.
- Pausar y continuar la reproducción.
- Pasar a la siguiente canción.
- Volver a la canción anterior.
- Controlar el volumen.
- Ver el progreso de reproducción.
- Abrir búsquedas de música en YouTube Music.
- Diseño adaptable para computadora y celular.

## 💻 Tecnologías utilizadas

### HTML
Se utiliza para crear la estructura de la página, como el menú, las secciones, las tarjetas de canciones y el reproductor.

### CSS
Se utiliza para diseñar la página, incluyendo colores, tamaños, posiciones, tarjetas, botones y adaptación para diferentes dispositivos.

### JavaScript
Se utiliza para agregar interactividad, como la búsqueda de canciones, selección de géneros, reproducción, pausa, siguiente canción, canción anterior, volumen y barra de progreso.
